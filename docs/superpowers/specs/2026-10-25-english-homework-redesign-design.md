## 1. 為什麼要重做

- 現在的單字練習 Ollie 看了不知道怎麼用 **【你決定】**。從程式看，可能的原因是 **【我的推論】**：
  - 一進頁面要先選「字數」和「CEFR 起始等級」才能產生功課，小孩不懂這些設定。
  - 一份功課拆成六個英文命名的步驟（Learn、Spell It、Fill in the Blank、What's the Word?、Write a Sentence、Spelling Test），可以任意順序做，畫面上沒有「現在該做哪一個」。
  - 題目、說明、回饋全部是英文，五年級的中文母語學生讀不懂說明。
- 生詞本的「複習」已經在 #29 移除，複習要整合進單字練習 **【你決定】**。「複習」其實就是「出功課」**【你決定】**。
- 整個核心要像國語出功課：練習寫單字、造句子；差別只是用電腦打字輸入 **【你決定】**。

## 2. 核心概念：英文作業簿

> **2026-10-25 修訂（你決定）：** 拿掉「造詞」，換成「例句填空」。英文的造詞幾乎都是「形容詞＋名詞」，和造句重疊、學不到新東西；例句填空練的是在句子裡認得這個字、寫出句子裡實際的字形（例如 `run` 在句子裡是 `ran`），電腦能自動批改。生字頁變成：看字 → 抄寫 3 遍 → 默寫 → 例句填空 → 造句。生詞本例句裡找不到這個字時跳過填空。舊功課停在造詞那一格的，接到例句填空；寫過的造詞仍顯示在紀錄裡。下文提到造詞的地方以這段為準。

> **2026-10-25 修訂（你決定）：** 加回 Gemini 批改造句。交作業時把整份功課的造句合併成**一次** Gemini 請求（action `sentence_review`），每句回傳是否正確、一到兩句繁體中文評語，以及需要時的修正句。評語顯示在寫完畫面和功課紀錄，家長仍然可以一起看。批改失敗不影響功課完成，畫面顯示「還沒改好」和「再改一次」；從紀錄打開沒有評語的舊功課，可以按「批改造句」。寫功課的過程中仍然不呼叫 Gemini，也不會自動重試。§8.4、§8.6「完全不呼叫 Gemini」以這段為準。

把國語的功課流程直接對應到英文 **【我的決定】**：

| 國語功課 | 英文功課 | 說明 |
|---|---|---|
| 生字簿：一個字一行，先看範字，再照著寫幾遍 | **抄寫**：看著單字打 3 遍 | 一個字一頁 |
| 不看範字自己寫 | **默寫**：單字遮住，聽發音打 1 遍 | 確認記住了 |
| 造詞 | **造詞**：用這個字寫一個短語，例如 `a curious cat` | 2–5 個英文字 |
| 造句 | **造句**：用這個字寫一個完整句子 | 交作業後由家長看 |
| 隔天聽寫 | **聽寫**：唸單字和例句，打出單字 | 包含今天的新字和要複習的舊字 |
| 聽寫錯了要訂正 | **訂正**：寫錯的字當場照著打 3 遍 | 下次聽寫再考 |

一份功課 = 幾個「新字」的生字頁，加上一場「聽寫」（新字＋複習字），聽寫完訂正。

## 3. 目標

- Ollie 打開「單字練習」就看到今天的功課，按一個按鈕就開始，不需要做任何設定 **【我的決定】**。
- 功課是一條直線：第 1 個字 → 第 2 個字 → … → 聽寫 → 訂正 → 完成。畫面永遠只有一個「下一步」**【我的決定】**。
- 說明文字用中文，練習內容（單字、例句、造詞造句）是英文 **【我的決定】**。現行設計「全英文」是 Ollie 看不懂的主因之一。
- 生詞本的字會定期回來複習：學會的字依間隔天數進入聽寫，寫錯就重新練 **【我的決定】**。
- 單字練習完全不呼叫 Gemini（見 §8.6）**【你決定】**。

## 4. 非目標

- 不做家長後台、多個孩子、老師帳號。家長用同一個帳號在「家長設定」調整 **【我的決定】**。
- 不做手寫輸入、拖曳、選擇題、配對 **【我的決定】**；延續「全部打字」的原則。
- 不做列印版。
- 不改生詞本畫面（#29 已定案），也不改 `vocabulary` collection 的結構。
- 不做排行榜、積分商店等遊戲化系統；完成時給簡單的鼓勵即可。

## 5. 反目標（技術上能動但仍算失敗的情況）

- **Ollie 不知道下一步要做什麼。** 任何畫面都必須有一個明顯的主要按鈕。
- **一份功課寫太久。** 預設份量要在 15–20 分鐘內寫完（§6.1）。
- **拼對的字判成錯。** 沿用現有 `answerMatch` 的規則：大小寫、前後空白、彎直引號不算錯。
- **作答時洩漏答案。** 輸入框關閉拼字檢查、自動完成、自動修正、自動大寫；默寫和聽寫時畫面上不能看得到這個字（包含例句裡的同一個字）。
- **偷偷呼叫 Gemini。** 產生功課、寫功課、交作業的任何一步送出 Gemini 請求，都算失敗（會撞到 4 RPM 和 429）。
- **語音壞掉就卡住。** 語音失敗可以重試或跳過，不算錯。
- **進度不見。** 關掉分頁隔天再開，要回到原來那一頁。
- **複習統計被清掉。** `reviewCount`、`rememberedCount`、`forgotCount` 等既有資料要保留，並繼續累加（§7.4）。

## 6. 功課內容

### 6.1 份量 【我的決定】

- **新字**：預設 5 個。
- **複習字**：聽寫時另外加入最多 10 個「到期」的舊字（§7）。
- 兩個數字都放在「家長設定」裡可以調整（新字 3–10、複習 0–20），記在 Firestore 的 practice state，換裝置也沿用。Ollie 的畫面上看不到這些設定。
- 估算時間：生字頁一個字約 2–3 分鐘，5 個字約 12 分鐘；聽寫 15 題約 5 分鐘。

### 6.2 新字怎麼選 【我的決定】

沿用現有 `wordPracticeSelection` 的規則，只是不再讓 Ollie 選起始等級：

1. 上次聽寫錯、還沒重新練過的字最優先（最近錯的排前面）。
2. 其餘「還沒練過」的字依 CEFR 由低到高；同等級先存進生詞本的先出。等級只用離線詞表查表（CEFR-J、Octanove），以及舊版已經存下來的 Gemini 估計值；**不再呼叫 Gemini 估計等級** **【你決定】**。查不到等級的字（多半是片語）排在所有有等級的字之後，彼此之間先存進生詞本的先出。
3. 沒有英文解釋、或不是英文字母開頭的字不能出（現有 `isEligibleWord`）。
4. 片語（例如 `look forward to`）可以出，抄寫和默寫打整個片語。

「起始等級」改成家長設定裡的選項，預設 A1。

### 6.3 什麼時候產生功課 【我的決定】

- 打開頁面時，如果沒有進行中的功課，畫面直接顯示「今天的功課」卡片：幾個新字、幾個複習字，以及一個「開始寫功課」按鈕。
- 卡片上的「幾個新字」顯示的是家長設定的數字（預設 5），不是實際算出來的數字：為了算實際可出的字，要讀整本生詞本，開頁面時不做這件事（§10）。實際數字在按下「開始寫功課」時才決定；可出的字比設定少，就用現有的字；一個都沒有時，在那時顯示「生詞本裡沒有可以練習的新單字」，若有到期的複習字，就只出聽寫 **【我的決定】**。「幾個複習字」可以只讀 state 文件算出來，照實顯示。
- 按下按鈕才真正產生功課。
- 一天可以寫不只一份；寫完後畫面顯示「再寫一份」。
- 同時只會有一份進行中的功課；放棄功課的按鈕放在家長設定裡，避免 Ollie 誤按。

## 7. 複習排程（取代生詞本的複習）

### 7.1 每個字的狀態 【我的決定】

存在現有的 `users/{uid}/wordPractice/state`，以正規化單字為 key（沿用）：

| 欄位 | 意思 |
|---|---|
| `stage` | 0 = 還沒練過；1–5 = 複習階段 |
| `dueAt` | 下次該進聽寫的時間（毫秒） |
| `lastResult` | 最近一次聽寫：`correct` / `wrong` |
| `needsPractice` | 聽寫寫錯、還沒重新聽寫寫對；下次功課優先當新字重練 |
| 既有的 `learnedAt`、`missCount`、`lastMissedAt` | 保留 |

### 7.2 規則 【我的決定】

- 寫完生字頁、聽寫也寫對 → 進入 stage 1，1 天後到期。
- 到期的字在聽寫寫對 → 往下一階：間隔依序為 1、3、7、14、30 天；stage 5 寫對後視為「熟了」，30 天後才再出現。
- 聽寫寫錯 → 當場訂正；回到 stage 0、`needsPractice: true`，下次功課當成新字優先重練（§6.2 第 1 點）。
- 新字在聽寫被跳過（語音失敗）→ 留在 stage 0，下次仍可能出現。
- 到期的字依到期時間排序，最早到期的先考；超過上限（預設 10）的留到下一份。

### 7.3 舊資料怎麼接上 【我的決定】

- **一次性轉換，寫回 state 文件**，不是每次讀取時推算。新版頁面第一次載入 state 時，如果文件沒有 `schemaVersion: 2`，就在一個 transaction 裡轉換並寫上 `schemaVersion: 2`；之後只看 `stage`、`dueAt`、`needsPractice`。
- 現行設計標成「學會」（有 `learnedAt`）的字 → stage 1，`dueAt` = 轉換的時間，也就是會陸續回到聽寫。
- 現行設計標成「錯過」（`missCount > 0`）而且沒有學會的字 → stage 0、`needsPractice: true`。
- 轉換後，選字和排程只用新欄位：
  - **新字候選** = stage 0 的字（包含從來沒出現在 state 裡的生詞本單字）。
  - **優先重練** = `needsPractice: true`。聽寫寫錯時設成 true；這個字在之後的功課裡**聽寫寫對**時才清掉（寫完生字頁還不算）。
  - `learnedAt`、`missCount`、`lastMissedAt` 保留並照舊更新，只作紀錄；不再用來判斷是否出題。
- `useCefrLevels` 如果讀了 `learnedAt` 做判斷，改成看 `stage > 0`；實作者確認它實際用途後調整。

### 7.4 生詞本的複習統計 【我的決定】

每次聽寫一個字（不論新字或複習字），用現有的 `updateReviewStats` 更新生詞本那個字的 `reviewCount`、`rememberedCount`／`forgotCount` 和 `lastReviewedAt`。這樣舊的複習紀錄會繼續累加，不會斷掉。找不到對應的生詞本記錄（例如已刪除）就略過。

## 8. 畫面與流程

### 8.1 頁面狀態 【我的決定】

| 狀態 | 畫面 |
|---|---|
| 沒有進行中的功課 | 「今天的功課」卡片＋「開始寫功課」；下方是寫過的功課紀錄 |
| 有進行中的功課 | 「繼續寫功課（第 3 / 5 個字）」大按鈕；下方是紀錄 |
| 寫功課中 | 全頁作業簿畫面（§8.2），上方有進度條和「先休息，等一下再寫」 |
| 寫完 | 成績與鼓勵、訂正結果，「回到首頁」或「再寫一份」 |

頁面上不再出現 CEFR、字數、步驟格子等設定；家長設定是頁面底部一個收合的區塊。

### 8.2 生字頁（每個新字一頁）【我的決定】

一次只顯示一段，像翻作業簿的格子：做完一段，這段收成上方一行小摘要（例如「✓ 抄寫 3 遍」），下一段出現，焦點自動移到它的輸入框 **【我的決定】**。這樣默寫時，前面看字和抄寫的內容已經收起來，畫面上不會有答案；默寫打對之後單字才重新顯示在頁面標題，造詞和造句時可以看著寫。存檔的續寫位置就是「第幾個字、第幾段」。

1. **看字**：單字、emoji、播放發音按鈕（進頁面自動播一次）、英文解釋（含詞性）和中文解釋、一句例句。
2. **抄寫 3 遍**：三個輸入框排成一列，像生字格。單字一直顯示在上面。每格打對才變綠色；打錯就標出錯的位置（沿用 `SpellingDiff`），清掉重打，不扣分。
3. **默寫 1 遍**：畫面上只有播放發音按鈕，以及把這個字遮成 `____` 的英文解釋和中文解釋（解釋裡出現的同一個字也遮住，沿用 `makeCloze` 的比對），打出單字。錯了顯示正確拼法和錯的位置，然後要再默寫一次直到打對。
4. **造詞**：「用 curious 寫一個短短的詞，例如 a curious cat」。本地檢查：要有這個字（允許字尾變化，沿用 `sentenceUsesWord`）、總共 2–5 個英文字。不呼叫 Gemini。
5. **造句**：「用 curious 寫一個完整的句子」。本地檢查：要有這個字、至少 4 個英文字。不呼叫 Gemini；交作業後由家長看（§8.4）。
6. 「下一個字」按鈕。

說明文字用中文，例子用英文。按 Enter 送出目前這一格。

### 8.3 聽寫 【我的決定】

- 題目 = 這份功課的新字＋到期的複習字，順序打亂。
- 每題唸法沿用現有拼字考試：單字 → 例句 → 再唸一次單字；可以重聽。沒有例句就只唸兩次單字。
- 每題只寫一次，作答時不顯示對錯。全部寫完才對答案。
- 寫錯的字立刻進入**訂正**：看著正確拼法打 3 遍（同抄寫），都打對才算完成。
- 語音失敗：顯示錯誤和重試；仍然失敗可以「跳過這題」，跳過的字不算對也不算錯，`dueAt` 不變。

### 8.4 交作業與家長批改

- 訂正完按「交作業」，功課完成，進入「寫完」畫面 **【我的決定】**。
- 造詞和造句**由家長看**，不用 Gemini 批改 **【你決定】**。電腦只做 §8.2 的本地檢查（有用到這個字、字數夠）。
- 「寫完」畫面和紀錄裡的每份功課，都列出這份功課每個字的造詞和造句，一個字一行，方便家長一次看完 **【我的決定】**。
- 這一版不做家長在 app 裡打勾或寫評語；家長看完當面跟 Ollie 講 **【我的決定】**。之後如果想在 app 裡留評語或改成 Gemini 批改，另外討論。

### 8.5 例句從哪裡來

- 只用已經存在的例句，**不呼叫 Gemini 補例句** **【你決定】**。順序：生詞本裡第一句含有這個字（允許字尾變化，沿用 `findExampleCloze`）的例句 → 這個字在以前功課快照裡存過的例句。
- 都沒有時：看字頁不顯示例句；聽寫只唸兩次單字（沿用現行做法）**【我的決定】**。
- 現有的 `generateExampleSentences`、`estimateCefrLevels`、`getSentenceFeedback` 從單字練習的流程拿掉，沒有其他地方使用的話就刪除。

### 8.6 Gemini 的使用

整個單字練習（產生功課、寫功課、交作業）**完全不呼叫 Gemini** **【你決定】**。

### 8.7 寫功課中可以離開 【我的決定】

- 每完成一格就存進度。
- 「先休息」回到首頁；回來時從同一個字、同一格繼續。

## 9. 資料與儲存 【我的決定】

- 繼續用 `users/{uid}/wordHomeworks/{homeworkId}` 和 `users/{uid}/wordPractice/state`，不新增 collection，Firestore 規則不用改。
- 功課文件加上 `version: 2`，內容是：新字快照（沿用 §7.5 的快照概念）、複習字快照、每個字每一格的進度、聽寫作答、訂正進度、造詞和造句的內容。
- 舊版（沒有 `version`）的功課：
  - 已完成的照樣顯示在紀錄裡（唯讀，用簡化的成績畫面）。
  - 進行中的舊功課在第一次開新版頁面時標成 `abandoned`，不影響任何字的狀態。
- 寫完功課時，用一個 transaction 同時更新功課文件和 state 文件（沿用現有做法）；生詞本的複習統計（§7.4）在 transaction 之後個別更新，失敗只記 log。

## 10. 限制

- 不使用 Gemini（§8.6）。
- Firestore 讀取額度有限：產生功課時讀生詞本全部單字沿用現有做法（一份功課一次），不要在每頁、每格作答時讀整本。
- 設計規範依 `AGENTS.md`（macOS HIG、淺色／深色、觸控目標 44px）。主要裝置是電腦，窄螢幕不能壞。
- 頁面在 auth 邊界內（沿用）。

## 11. 留給實作者

- 元件拆分與命名，以及舊步驟元件（`steps/*`）哪些改寫重用、哪些刪除。`SpellingDiff`、`AnswerInput`、`answerMatch`、`wordForms`、CEFR 查表、例句準備都應該重用。
- 造詞 2–5 字、造句至少 4 字的本地檢查細節（標點、縮寫怎麼算字數）。
- 「寫完」畫面的鼓勵動畫（可用 `canvas-confetti`）。
- 家長設定區塊的位置與樣式。
- 測試切分；至少涵蓋：複習排程（升階、降階、到期排序、上限）、舊資料轉換、生字頁每一格的完成條件、聽寫與訂正、沒有例句時的聽寫、整個流程不呼叫 Gemini。

## 12. 驗收情境

1. 生詞本有 8 個沒練過的字。打開單字練習，不做任何設定，按「開始寫功課」，得到 5 個新字的功課。
2. 生字頁：抄寫打錯會標出錯的位置；默寫時畫面上看不到這個字；造詞只有一個字、或造句沒有用到這個字時，直接提示。
3. 寫到第 3 個字的造詞時關掉分頁，重新打開後回到同一格。
4. 聽寫寫錯 1 個字：寫完後要訂正 3 遍；下一份功課這個字排在新字最前面。
5. 聽寫寫對的新字 1 天後出現在下一份功課的聽寫裡；再寫對就變成 3 天後。
6. 從產生功課到交作業，整個過程沒有送出任何 Gemini 請求；「寫完」畫面和紀錄裡看得到每個字的造詞和造句。
7. 每聽寫一個字，生詞本那個字的 `reviewCount` 加一，`rememberedCount` 或 `forgotCount` 依對錯加一。
8. 舊版有 `learnedAt` 的字，在新版第一份功課的聽寫裡出現。
9. 舊版已完成的功課在紀錄裡看得到。
10. Ollie 看得到的畫面上沒有 CEFR、字數等設定；家長設定可以改新字數量和複習上限。
11. 淺色與深色主題、1440px 與 768px 寬度下版面正常；所有輸入框沒有拼字檢查紅線。
12. 生詞本裡沒有可用例句的字，看字頁不顯示例句，聽寫只唸兩次單字。
